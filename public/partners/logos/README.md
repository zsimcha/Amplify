# Partner logos

Drop each organization's logo here as a **PNG**, named exactly as listed below.
Missing files fall back to the org name in text, so you can upload these one at
a time — nothing breaks in the meantime.

Ideally transparent-background PNGs, roughly square or wide (they get scaled to
fit inside logo tiles and a scrolling marquee, so very tall/narrow logos will
look cramped).

Delete this file once all logos are uploaded — it's just a placeholder so this
folder exists in the repo.
